# AWS SDK for Java v2 General Guidelines

## Development Environment

- **Java Version**: Java 8 is the target language version for the AWS SDK for Java v2
- **Build System**: Maven is used for building and dependency management

## Build Instructions

Build, test and verification commands, and the rules for running them quickly, are in
[docs/guidelines/building-and-testing.md](../../docs/guidelines/building-and-testing.md). The
`building-and-testing.md` steering file always includes it.
